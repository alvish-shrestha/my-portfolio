# Alvish Shrestha — Fancy Animated Portfolio

Built with **React + Vite**, **Tailwind CSS**, **Framer Motion**, and **react-scroll**.

## ✨ Features
- Smooth scrolling navigation
- Animated hero, skill bars, and project cards
- Responsive design and modern gradient accents
- Easy config via `src/data.js`

## 🚀 Getting Started
```bash
# 1) Install deps
npm install

# 2) Start dev server
npm run dev

# 3) Build for production
npm run build && npm run preview
```

## 🔧 Customize
- Update links, skills, and projects in `src/data.js`
- Replace images in `src/assets/`
- Edit copy in `src/sections/*`

## ☁️ Deploy
- **Vercel**: Import this repo → Build Command: `npm run build` → Output: `dist`
- **Netlify**: Build Command: `npm run build` → Publish Directory: `dist`
- **GitHub Pages**: Use `vite` + `gh-pages` (or deploy with GitHub Actions)
